# Incognito Love 🤖

Анонімний дейтинг бот для Telegram з системою токенів та донатів.

## 🌟 Функції

- 🔍 Анонімний пошук анкет
- 💬 Анонімний чат з метчем
- 🪙 Система токенів
- 💰 Донати через DonationAlerts та Monobank
- 🎁 Подарунки за токени
- ⭐ Супер-лайки
- 📊 Профіль та статистика
